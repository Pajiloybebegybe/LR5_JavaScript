
# Лабораторная работа №5
## Основы JavaScript и проектирования компонентов

**Вариант:** 2

## 1. Описание проекта

Данный проект представляет собой интерактивную веб-страницу, разработанную с использованием HTML, CSS и JavaScript.

Цель работы — изучение основ JavaScript, обработка пользовательских событий, создание интерактивных компонентов и применение принципов проектирования веб-интерфейсов.

В проекте реализованы следующие компоненты:

1. Таймер обратного отсчёта.
2. Аккордеон с возможностью сортировки элементов.
3. Слайдер изображений с настройками скорости и направления прокрутки.
4. Вкладки (Tab-панель).
5. Список задач To-Do.
6. Генератор случайных чисел.
7. Выпадающее меню.
8. Модальное окно с возможностью перемещения и изменения размера.

## 2. Структура проекта

```text
LR5_JavaScript/
│
├── index.html
│
├── css/
│   └── style.css
│
├── js/
│   └── script.js
│
└── README.md
```

### Назначение файлов

- `index.html` — содержит структуру веб-страницы и HTML-разметку компонентов.
- `css/style.css` — отвечает за оформление, расположение элементов, цвета, адаптивность и анимации.
- `js/script.js` — содержит JavaScript-код, обеспечивающий интерактивность компонентов.
- `README.md` — описание проекта и инструкция по его запуску.

## 3. Используемые технологии

В проекте применяются:

- **HTML5** — создание структуры веб-страницы.
- **CSS3** — оформление интерфейса, адаптивная вёрстка и анимации.
- **JavaScript (ES6+)** — обработка событий и реализация интерактивных функций.

Дополнительные библиотеки и фреймворки не используются.

## 4. Описание компонентов

### 4.1. Таймер обратного отсчёта

Позволяет пользователю задать количество секунд и запустить обратный отсчёт.

Реализованы функции:
- запуск таймера;
- приостановка отсчёта;
- сброс таймера;
- отображение оставшегося времени в формате минут и секунд.

### 4.2. Аккордеон с сортировкой

Компонент содержит раскрывающиеся информационные блоки с описанием HTML, CSS и JavaScript.

Реализованы:
- раскрытие и сворачивание блоков;
- визуальное изменение состояния элементов;
- изменение порядка элементов посредством Drag and Drop.

### 4.3. Слайдер изображений

Предназначен для последовательного просмотра изображений.

Реализованы:
- переключение изображений вперёд и назад;
- автоматическая прокрутка;
- изменение скорости прокрутки;
- выбор направления движения;
- отображение от одного до трёх изображений одновременно;
- навигация с помощью индикаторов.

### 4.4. Вкладки

Позволяют переключаться между информационными разделами HTML, CSS и JavaScript без перезагрузки страницы.

### 4.5. Список задач To-Do

Предназначен для управления списком задач.

Реализованы:
- добавление новых задач;
- отметка выполненных задач;
- удаление задач;
- добавление задачи нажатием клавиши Enter.

### 4.6. Генератор случайных чисел

Позволяет генерировать случайное целое число в заданном пользователем диапазоне.

Перед генерацией выполняется проверка введённых значений.

### 4.7. Выпадающее меню

Предоставляет возможность выбора раздела веб-страницы.

Реализованы:
- открытие и закрытие меню;
- анимация появления;
- выбор пункта меню;
- переход к соответствующему разделу;
- закрытие при нажатии за пределами меню или клавиши Escape.

### 4.8. Модальное окно

Дополнительный интерактивный компонент.

Реализованы:
- открытие и закрытие окна;
- закрытие нажатием на затемнённую область;
- закрытие клавишей Escape;
- перемещение окна при помощи мыши;
- изменение размеров окна перетаскиванием нижнего правого угла.

## 5. Запуск проекта

Для запуска проекта необходимо:

1. Скачать или скопировать папку `LR5_JavaScript`.
2. Убедиться, что внутри присутствуют файлы `index.html`, `css/style.css` и `js/script.js`.
3. Открыть файл `index.html` в любом современном браузере.
4. Использовать интерактивные элементы веб-страницы.

Дополнительная установка программного обеспечения не требуется.

## 6. Проверка проекта

HTML-разметка проверена с помощью W3C Markup Validation Service.

CSS-стили проверены с помощью W3C CSS Validation Service.

В ходе проверки ошибок не обнаружено.
