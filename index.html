2. Аккордеон с сортировкой

HTML — язык гипертекстовой разметки, который используется для создания структуры веб-страниц.
CSS — язык стилей, предназначенный для оформления веб-страниц и управления их внешним видом.
JavaScript — язык программирования, который позволяет добавлять интерактивность и динамическое поведение.

HTML

HTML отвечает за создание структуры веб-страницы. С его помощью размещаются заголовки, изображения, текст, кнопки и другие элементы.

CSS

CSS используется для оформления веб-страниц. Он позволяет задавать цвета, размеры, расположение элементов и анимации.

JavaScript

JavaScript позволяет создавать интерактивные элементы, обрабатывать события и изменять содержимое веб-страницы.
